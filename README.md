# 学習発表会 ポン出しプレイヤー（タブレット対応版）

## 公開方法
このフォルダー内の `index.html` `manifest.webmanifest` `sw.js` の3ファイルを、同じ階層のままGitHubリポジトリへアップロードしてください。GitHub Pagesを有効にするとURLで配付できます。

## 使い方
- iPad：SafariでURLを開き、共有メニューから「ホーム画面に追加」
- Android：ChromeでURLを開き、メニューから「ホーム画面に追加」または「アプリをインストール」
- 「音源を追加」から端末内の音声ファイルを選択
- 音源データとボタン設定はIndexedDBに自動保存されます（同じ端末・同じブラウザ内）
- 「バックアップ」で音源データを含むJSONを書き出し、「復元」で別端末へ移行できます

## 注意
- 端末内保存は端末・ブラウザごとに独立しています。ほかの人の設定とは共有されません。
- ブラウザのサイトデータ削除、端末の初期化、容量不足などで保存データが消える可能性があります。大切な音源は定期的にバックアップしてください。
- バックアップJSONには音源そのものが含まれるため、ファイルサイズが大きくなる場合があります。
- PWAとしてのホーム画面追加・Service WorkerはHTTPSで公開した場合に動作します。
- Tailwind CSSとLucideアイコンはCDNを利用しています。初回表示時はインターネット接続が必要です。
